# Hi, I'm Gopi Pamulapati 👋

**Senior Gen AI / ML Engineer** with 8+ years of experience building LLM, RAG and agentic AI
systems for production in **financial services** and **pharma**.

I focus on the parts that make LLM systems reliable in regulated domains: retrieval quality,
agent orchestration, evaluation and guardrails, and shipping them as tested, containerized
services.

## Featured projects

| Project | What it shows |
|---|---|
| [**clinical-ade-qlora**](https://github.com/gopipamulapati/clinical-ade-qlora) | **QLoRA / PEFT** fine-tuning of Qwen2.5 / Llama 3.2 to extract adverse drug events from clinical notes as schema-validated JSON: label-masked SFT, before/after evaluation, FastAPI serving |
| [**drug-safety-mcp**](https://github.com/gopipamulapati/drug-safety-mcp) | **MCP server** exposing FDA drug-safety data (labels, FAERS adverse events, recalls, interactions) with structured outputs, plus a LangGraph agent that discovers and uses its tools |
| [**llm-eval-guardrails**](https://github.com/gopipamulapati/llm-eval-guardrails) | **Evaluation + guardrails** for LLM/RAG apps: faithfulness and LLM-as-judge metrics, prompt-injection / PII / grounding guards, a FastAPI sidecar, and a CI gate that fails PRs on quality regressions |
| [**loan-review-agents**](https://github.com/gopipamulapati/loan-review-agents) | Multi-agent mortgage pre-review with **LangGraph**: LLM extraction with schema validation, parallel policy and risk agents, a decision-lock guardrail, FastAPI, Docker, CI, OpenAI / AWS Bedrock |
| [**rag-engineer-portfolio**](https://github.com/gopipamulapati/rag-engineer-portfolio) | Three RAG projects: hybrid retrieval (BM25 + dense + RRF + cross-encoder reranking) with Hit Rate / MRR evaluation, a ReAct-style agentic multi-document RAG, and [conversational RAG with memory](https://github.com/gopipamulapati/rag-engineer-portfolio/tree/main/conversational-rag-langgraph) on LangGraph (session memory, grounding self-check, streaming) |
