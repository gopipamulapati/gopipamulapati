# Hi, I'm Gopi Pamulapati 👋

**Senior Gen AI / ML Engineer** with 8+ years of experience building LLM, RAG and agentic AI
systems for production in **financial services** and **pharma**.

I focus on the parts that make LLM systems reliable in regulated domains: retrieval quality,
agent orchestration, evaluation and guardrails, and shipping them as tested, containerized
services.

## Featured projects

| Project | What it shows |
